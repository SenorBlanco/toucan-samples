Toucan Samples

The Toucan Samples are a set of samples demonstrating the use of the experimental Toucan language.

These samples run in Google Chrome 137+, Firefox 153+, and Safari 27+.

WebGPU is enabled by default on most platforms in Chrome. To enable WebGPU on Linux, navigate to chrome://flags, and enable "Vulkan" and "Unsafe WebGPU Support".

Demo Source Description
Hello, Triangle triangle.t The canonical "Hello, Triangle" example, now in green.
Shiny Teapot shiny.t An environment-mapped teapot in a skybox of the same texture.
Shiny Dragon shiny-dragon.t An environment-mapped dragon in a skybox of the same texture.
Shiny Teapot (animated) shiny-anim.t Animated teapot via Bezier patch animation on the host CPU.
Shiny Teapot (animated via compute) shiny-compute-anim.t Animated teapot via Bezier patch animation in a GPU compute shader.
Springy springy.t A particle physics demo, with a 10x10 grid of particles connected by springs.
Springy (compute) springy-compute.t The same particle physics demo, running in a GPU compute shader.
Springy 3D springy-3d.t A particle physics demo, with a 20x20x20 mesh of particles.
Springy 3D (compute) springy-compute-3d.t Same as above, running in a compute shader.
Disco Dragon disco-dragon.t A Toucan port of the Deferred rendering WebGPU sample.
HDR Image Explorer hdr-image-explorer.t An UltraHDR JPEG image, imported and displayed in Toucan. The mouse/touch controls a high gain "flashlight" to explore the dark regions.
